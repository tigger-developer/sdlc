#   Level-four headings identify individual ACs when their text needs detail.

# - Use bullets only for short, flat lists of peers such as summary statistics
#   or the final delivered-ticket index.

# - Inline commands, paths, and identifiers use Org verbatim markers:
#   =make test= or =docs/ACs.org=.
# - Never use Markdown backticks or escaped backticks in this Org file.
