#+begin_comment
This is the canonical SDLC v3 work-ledger template.

Use real Org headings and one monotonically increasing project-wide work number.
Never reuse an identifier, including after abandonment or archival. Put work
identity, state, priority, provenance, and links here. Put acceptance criteria,
test definitions, edge cases, and solution design in the linked spec.org.
#+end_comment
