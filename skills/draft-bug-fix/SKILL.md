---
name: draft-bug-fix
description: Compatibility entry point for projects moving bug specifications to Spec Kit.
---

This SDLC no longer defines a bug-ticket workflow. In a Spec Kit project, amend
the affected specification through the project's Spec Kit workflow: cite the
violated requirement with its descriptor, or add the missing behaviour before
implementation. Use any installed bug extension if the project has selected
one. Do not create a second source of truth.
