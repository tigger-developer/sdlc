name: draft-design-issue
description: Compatibility entry point for projects moving specification and design to Spec Kit.
---

This SDLC no longer combines GitHub issue drafting and solution design. In a
Spec Kit project, use the active integration's `speckit.specify` command and
then `speckit.plan`; they own `spec.md` and `plan.md`. Do not create a
parallel SDLC issue or design artefact.
