---
name: design-solution
description: Compatibility entry point for projects moving solution design to Spec Kit.
---

This SDLC no longer defines a solution-design workflow. In a Spec Kit project,
use the active integration's `speckit.plan` command; it owns `plan.md`.
Outside Spec Kit, use the project's documented planning mechanism. Do not create
a parallel SDLC design artefact.
