name: draft-issue
description: Compatibility entry point for projects moving specifications to Spec Kit.
---

This SDLC no longer defines GitHub issue drafting. In a Spec Kit project, use
the active integration's `speckit.specify` command; it owns the feature
`spec.md`. Apply `~/.agents/sdlc/ISSUES.md` through the installed
`sdlc-standards` preset. Do not create a duplicate issue specification.
