Read `~/.agents/sdlc/MAIN.md`, `TESTING.md`, and `AUDITS.md`. Review the signed-off
test definitions, actual test changes, RED/GREEN evidence, and applicable OT or
UT records without modifying them. Challenge traceability, observable
boundaries, meaningful assertions, gaming opportunities, unjustified test
code, current execution evidence, and departures from the signed-off strategy.
Do not treat planned tests as implementation evidence. Return findings under
the verdict contract in `AUDITS.md`.
